# 本地 EPUB 小说阅读器设计规格

## 1. 目标

构建一个面向桌面浏览器的纯前端 EPUB 小说阅读器。用户可以导入本地、无 DRM 的 `.epub` 文件，在浏览器中离线阅读；书架、书籍文件、阅读进度、书签和阅读偏好会在重启浏览器后恢复。

首版成功标准是提供可靠、沉浸且可恢复的核心阅读闭环，而非在线内容平台。

## 2. 用户与使用场景

目标用户是在桌面浏览器中阅读已下载小说 EPUB 文件的个人用户。

典型流程：

1. 用户打开书架并导入一个或多个本地 EPUB 文件。
2. 用户从书架打开书籍，使用目录或翻页进行阅读。
3. 用户调整字号、字体、行高和主题，或对当前位置添加书签。
4. 用户关闭或重新打开浏览器后，从书架继续阅读，并恢复上次位置与偏好。

## 3. 范围

### 3.1 首版包含

- 本地 `.epub` 文件选择、格式校验、导入和删除。
- 本地书架：封面网格、书名/作者、继续阅读标识和最近阅读排序。
- EPUB 正文渲染、上一页/下一页、目录跳转和当前章节高亮。
- 阅读位置与全书进度展示及恢复。
- 书签的新增、删除、列表与跳转。
- 字号、字体、行高、浅色/深色/护眼主题等阅读偏好。
- 每本书可独立选择本地图片作为阅读背景，并可启用、关闭或调节文字阅读蒙层强度。
- 浏览器本地离线持久化。
- 加载、空书架、无封面/无目录及无效文件等可理解状态。

### 3.2 首版不包含

- 在线书库、账户、服务端、上传和多设备同步。
- 受 DRM 保护的 EPUB。
- 划线、笔记、全文搜索、阅读统计和朗读。
- 原生桌面应用、移动端专门布局或 PWA 安装体验。

移动窄窗口仅保证页面不崩溃且可滚动；完整交互以桌面 Chromium 浏览器为验收目标。

## 4. 技术决策

采用 `React + TypeScript + Vite + epub.js + IndexedDB` 的纯前端单页应用。

| 决策 | 选择 | 原因 |
| --- | --- | --- |
| UI 框架 | React + TypeScript | 适合状态复杂的阅读器界面，类型可约束持久化数据与渲染事件。 |
| 构建工具 | Vite | 开发启动快，适合独立前端应用。 |
| EPUB 引擎 | epub.js | 处理 EPUB 解包、目录、分页、CFI 定位与渲染，避免自行解析 EPUB。 |
| 持久化 | IndexedDB | 可保存 EPUB Blob，不依赖仍有效的文件系统句柄；容量与异步访问比 `localStorage` 更适合书籍文件。 |
| 数据访问 | 独立 repository 层 | 将 IndexedDB 细节隔离在 UI 之外，便于测试、迁移和处理事务。 |

不在首版加入 PWA。离线阅读已经由本地 IndexedDB 实现；Service Worker 与缓存更新策略对当前范围没有足够收益。

## 5. 架构

应用以路由或显式页面状态区分书架页与阅读页。所有文件、业务状态和偏好仅保存在当前浏览器配置文件中。

```text
书架页 / 阅读器页
        |
        v
UI 组件层
        |
        +----------------------+--------------------+
        |                      |                    |
        v                      v                    v
LibraryService          ReaderService        PreferencesService
        |                      |                    |
        +----------------------+--------------------+
                               |
                               v
                    Persistence Repository
                               |
                               v
                          IndexedDB

ReaderService <----> epub.js <----> EPUB Blob
```

### 5.1 模块职责

| 模块 | 职责 | 依赖 |
| --- | --- | --- |
| `library` | 导入、读取书架、删除书籍、排序 | repository、EPUB 元数据提取器 |
| `reader` | 打开 EPUB、渲染、翻页、目录跳转、CFI 与进度处理 | epub.js、repository |
| `bookmarks` | 创建、删除、列出、跳转书签 | reader、repository |
| `settings` | 维护并应用阅读样式偏好 | repository、epub.js 内容样式接口 |
| `persistence` | 以类型化接口封装 IndexedDB 的读写与级联删除 | IndexedDB |
| `ui` | 页面状态、布局、可访问操作与错误反馈 | 各服务的公开接口 |

UI 组件不得直接操作 IndexedDB。epub.js 实例只由阅读器服务创建和销毁，离开阅读页时必须清理渲染实例和事件订阅。

## 6. 数据模型

### 6.1 `books`

每条书架记录包含：

- `id`：应用生成的稳定 ID。
- `title`、`creator`、`language`：由 EPUB 元数据获取，缺失时使用文件名或“未知作者”等明确回退值。
- `coverBlob`：可选封面图像 Blob。
- `fileBlob`：原始 EPUB Blob。
- `importedAt`、`updatedAt`：导入与最后阅读时间。

### 6.2 `readingStates`

以 `bookId` 为键，保存：

- `cfi`：epub.js 当前定位 CFI，是恢复位置的权威值。
- `progression`：0 至 1 的近似全书进度，仅用于展示。
- `chapterLabel`：最近章节名称，用于书架辅助信息。
- `updatedAt`：最近阅读时间，用于排序和展示。

### 6.3 `bookmarks`

每个书签保存 `id`、`bookId`、`cfi`、`chapterLabel`、短文本摘录和 `createdAt`。同一本书同一 CFI 不重复创建书签。

### 6.4 `preferences`

单条用户偏好保存字体族、字号、行高、主题和目录栏显示状态。它在当前浏览器内对所有书籍生效。

### 6.5 `bookReaderAppearances` 与 `backgroundImages`

每本书可选的一条 `bookReaderAppearance` 记录以 `bookId` 为键，保存：

- `backgroundImageId`：可选的本地背景图片 ID。
- `backgroundEnabled`：背景是否在阅读器中显示。
- `overlayOpacity`：0.2 至 0.9 的文字阅读蒙层不透明度，默认值为 0.55；较高值提高文字与背景的对比度。

背景图片以独立的 `backgroundImages` 记录保存，包含 `id`、`bookId`、原始图片 Blob、MIME 类型和创建时间。每本书仅保留当前选定的一张图片；替换图片时删除旧 Blob 再写入新 Blob，避免无主大文件。

删除书籍须在同一逻辑操作中删除该书的阅读状态、所有书签、阅读外观记录和背景图片，避免孤立数据。

## 7. 界面与交互

### 7.1 书架

书架页以封面网格展示书籍，卡片显示封面、书名、作者、阅读进度与最近阅读时间。页面提供显眼的“导入 EPUB”入口；空书架显示说明与导入按钮。书籍默认按最近阅读时间排序；卡片可打开阅读器或触发删除确认。

### 7.2 阅读器

桌面默认布局为左侧固定目录栏加中央正文阅读区：

- 左栏显示书名、章节树和书签列表；章节可展开，当前章节高亮，书签可跳转。
- 中间区域以最大可读宽度渲染正文，避免正文随左栏宽度变化而过窄。
- 顶部紧凑工具栏提供返回书架、上一页、下一页、进度显示、目录栏显隐、书签切换和设置入口。
- 设置面板包含字号、字体、行高与浅色/深色/护眼主题，变更即时生效并持久化。
- 设置面板的“阅读背景”分组提供本地图片选择、替换、启用/关闭、阅读蒙层强度调节和恢复该书默认背景。背景只对当前书籍生效，不改变其他书籍的设置。

键盘支持方向键、`PageUp`、`PageDown` 和空格翻页；`Esc` 关闭设置面板。所有图标按钮都提供可访问名称与悬浮说明。

### 7.3 状态保存与恢复

发生分页、目录跳转、书签切换或离开阅读页时，应用对当前位置去抖保存。重新打开书籍时优先由保存的 CFI 恢复；如果该 CFI 不可用，回退到书籍开头并更新状态。书架读取阅读状态展示进度和继续阅读信息。

### 7.4 背景图渲染

阅读器将图片作为正文下方的独立背景层，以 `cover` 模式覆盖可视阅读区域。阅读器服务向 epub.js 的渲染内容注入受控样式，使 EPUB 根元素与正文背景透明；正文上方保持独立蒙层，并由 `overlayOpacity` 调节其不透明度。此方案让图片在多页与章节切换时保持稳定，也不修改 EPUB 原始 Blob 或其内部文件。

背景图上传前只接受 JPEG、PNG 与 WebP，文件上限为 10 MB；成功保存后立即预览。关闭背景不会删除图片，恢复默认背景才删除该书背景图和外观记录。没有背景图或图片加载失败时，阅读器回退到当前主题的纯色背景。

## 8. 异常与降级

- 文件不是 `.epub`、无法解析、损坏或受 DRM 保护：显示明确错误，且不写入书架。
- EPUB 没有封面：使用稳定的文本封面占位样式。
- EPUB 没有目录：隐藏章节树，阅读器保持翻页功能。
- 章节为空或资源加载失败：显示章节级提示，保留返回、目录和翻页能力。
- IndexedDB 写入失败或空间不足：提示保存失败，不伪称状态已持久化；当前会话阅读尽量继续。
- 恢复 CFI 失败：从书籍开头打开并明确说明已回退。
- 背景图不是浏览器可解码的图片、过大而导致写入失败或加载失败：不改变现有背景，说明失败原因并提供重新选择入口。

## 9. 测试与验收

### 9.1 自动化测试

- 单元测试：ID 与数据映射、进度计算、书签去重、偏好转换、背景外观映射、repository 级联删除与错误处理。
- 组件/集成测试：导入工作流、书架排序、状态保存、目录跳转、书签切换、设置即时应用和背景图替换/恢复默认。
- 端到端测试：基于可提交的无 DRM EPUB 样本，覆盖导入、打开、翻页、目录跳转、设置、添加书签、每书设置背景图、刷新/重开后恢复及删除。

### 9.2 手工验收矩阵

- 正常小说 EPUB。
- 无封面 EPUB。
- 无目录 EPUB。
- 超长目录 EPUB。
- 损坏或伪装为 EPUB 的文件。
- 深色、浅色与护眼主题。
- 为两本书设置不同背景图，验证彼此不串用，关闭背景与恢复默认均生效。
- 调整最大/最小字号和行高。
- 关闭并重新打开浏览器后恢复书架、书签、偏好与位置。

### 9.3 完成定义

在桌面 Chromium 浏览器中，用户可以导入多本本地无 DRM EPUB，离线保存在书架并重启浏览器后再次打开；能通过目录和翻页稳定阅读；阅读位置、书签、阅读偏好及每本书独立的背景图设置准确恢复；无效或不完整内容得到清楚反馈且不影响已有书架。

## 10. 后续迭代候选

在首版稳定后，可按价值顺序评估全文搜索、划线与笔记、PWA 安装、阅读统计、可导出数据备份及跨设备同步。它们均不影响本设计的本地数据边界：后续功能应通过 repository 和服务层访问数据，不应让 UI 直接依赖 IndexedDB 实现。
