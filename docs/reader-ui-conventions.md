# 已确认的阅读器界面约定

2026-10-04 用户确认，后续 Windows 和 Android 更新沿用此形式。

- 侧栏保持目录、书签、阅读设置、背景图片上下排列的结构。
- 仅侧栏最外层右侧滚动条可见。内部区域隐藏滚动条外观，保留其原有滚动能力；不能通过禁用滚动或统一接管滚动来实现。
- 目录每层固定缩进 12px，同层标题对齐，长标题换行与自身文字起点对齐。
- 普通目录项背景透明，只在当前章节或鼠标悬停时高亮；有子目录的条目提供展开、收起箭头，箭头与标题跳转分别操作。
- “显示目录栏”勾选框和文字同排对齐。
- 阅读设置包含“背景板透明度”：0% 不透明，100% 全透明，仅影响正文后方的背景板，文字保持清晰，设置自动保存。
- 章节切换、目录跳转后，正文仍可连续使用滚轮、左键、右键翻页；手机保留左右滑动、底部按钮、抽屉侧栏和系统返回键处理。
- 手机正文点击区域为左侧45%上一页、右侧45%下一页、中间10%切换顶部和底部操作栏。隐藏操作栏时阅读区扩展，点击与滑动翻页继续有效；系统返回键优先恢复操作栏。
- 阅读加载时兼容图片标签缺少 `alt` 属性值的 XHTML，恢复完整章节和插图；保留原 EPUB 文件及既有阅读数据。
- 保留原有应用标识、数据存储与签名方式，更新包不得重置用户的书架、书签和进度。
- Windows 和 Android 应用图标采用工作区的 `ciallo 图标.jpg`，保留完整画面与比例。方形图标母版为 `src-tauri/icons/app-icon.png`，通过 `icon-manifest.json` 生成多尺寸图标；Android 同时提供普通、圆形和自适应图标。
- 发布文件统一命名为 `release/Local EPUB Reader.exe` 与 `release/Local EPUB Reader.apk`；发布目录仅保留最新版。
- 支持从系统直接打开 EPUB：首次自动加入书架并阅读；相同内容重复打开、改名或移动后打开，复用已有图书及记录。Windows 使用单实例接收文件参数；Android 支持打开方式和分享，并处理首次启动与已运行时的新文件。

修改这些已确认的形式前，先与用户讨论。
